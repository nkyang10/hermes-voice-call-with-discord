# Contributing

Thanks for your interest! This is a small personal project, but contributions, issues, and ideas are welcome.

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-change`
3. Make your changes
4. Write or update tests as needed
5. Run tests: `python -m pytest tests/ -v`
6. Commit with a clear message
7. Push and open a Pull Request

## Code Style

- Python 3.10+ type hints preferred
- Ruff-compatible (linting runs in CI)
- Keep emoji-prefixed log messages for consistency (✅, ❌, ⚠️, 🎤, 🗣️, etc.)

## Reporting Issues

Open an issue with:

- What you were doing
- What you expected to happen
- What actually happened
- Relevant log output (if available)
